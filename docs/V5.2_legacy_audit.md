# V5.2 遗留词库审计 + 生产就绪（production_ready）

## 目标
给既有遗留 2000 词建立可信度基线，让「哪些词可以进生产」变成可判定、可追溯的规则。

## 交付内容

### 新增列：`production_ready`
`lexicon_entries` 表新增布尔列，并**登记进 `schema_compat` 增量迁移清单**。

### 判定规则（`lexicon/production_ready.py`）
一条词只有同时满足才算「生产就绪」：

1. **来源已 verify**（在 `license_registry.json` 中登记为可信来源）
2. **commercial_allowed** 为真（授权允许商用）
3. **必填字段有效**：surface / 释义 / 例句等必须齐全且非空

### 不可动摇的红线
> **`synthetic-dev` 来源的词永远为 `False`**

合成测试数据是开发用的，任何时候都不能混进生产内容。这条规则由测试 `test_v53_production_ready.py` 锁定。

## 审计脚本
| 脚本 | 用途 |
|---|---|
| `scripts/audit_legacy_content.py` | 审计遗留词条内容完整度 |
| `scripts/audit_legacy_audio.py` | 审计音频文件是否存在、有无孤儿文件 |
| `scripts/import_legacy_lexicon.py` | 遗留词导入主词库 |
| `scripts/recompute_production_ready.py` | 按当前规则幂等重算 |

审计结果输出到 `data/lexicon/audit/*.json`。
