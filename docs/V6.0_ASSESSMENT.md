# V6.0.1 AI Assessment + V6.0.2 Learner Model

> 状态：已实现核心闭环（V6.0.0 提交）。本文件记录「学习者是谁、会什么、不会什么」的数据底座。

## 数据模型

不重复改造既有 `UserOnboarding`（仅承载注册向导的粗粒度字段），新增两张结构化表：

- **`learner_profiles`**（状态）：`user_id` 主键 + 母语/目标语 + 六维技能等级
  `vocab/grammar/reading/listening/speaking/writing_level` + `overall_level` +
  `weak_areas`（逗号分隔技能 key）+ `learning_preferences` + `updated_at`。
- **`assessments`**（事件/快照）：每次评估的六维结果 + `answers`（JSON 作答历史）+ `created_at`。
  与 `learner_profiles` 解耦：`Assessment` 是"发生了一次评估"，`LearnerProfile` 是"当前状态"。

两者通过 `User.learner_profile` / `User.assessments` 反向关系连接（级联删除，用户注销不残留）。

## 评估引擎（`assessment.py`）

- `generate_assessment(user_id)`：从既有 `Word` 表抽词，为 vocab/reading/listening/grammar
  构造 MCQ（含 `audio_url` 复用 2000 MP3）；speaking/writing 在 Mock 阶段无法自动判分，
  改为**自评**（1–5）并明确标注，**不伪装成客观成绩**。题目以 JSON 随表单提交回传，避免随机重建导致判分错位。
- `grade_assessment(questions, submitted)`：MCQ 客观判分；自评按 `值/5` 归一；
  六维正确率 → CEFR 等级（`_level_from_accuracy`：<0.4→A1，<0.7→A2，<0.85→B1，<0.95→B2，否则 C1，
  **初测不臆造 C2**）；overall 取六维平均；弱项 = 落在 A1 的维度。
- `save_assessment(...)`：写 `Assessment` 快照并 upsert `LearnerProfile`。

## 路由与界面

- `GET/POST /assessment/`：生成 → 提交判分 → 保存 → 重定向结果页（带 CSRF token）。
- `GET /assessment/result/<aid>`：仅本人可见（**IDOR 防护**：非本人 `abort(403)`）。
- 导航新增「Assessment 能力评估」入口；新增 `assessment.html` / `assessment_result.html` 与 `v4.css` 样式。

## 诚实性说明

- 自动判分技能基于真实词库数据；speaking/writing 自评明确标注，评分不混入客观成绩。
- 等级映射是透明的正确率阈值，无黑盒、无机器学习框架（符合 V6.0 轻量约束）。
- `overall` 不会因自评满分而越过 C1，避免伪造高水平。
