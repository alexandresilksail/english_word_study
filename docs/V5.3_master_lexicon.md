# V5.3 English Master Lexicon（主词库引擎）

## 目标
建立结构化、去重、分级、可溯源的英文主词库，作为全站词汇数据的单一来源。

## 交付内容

### 模型：`LexiconEntry`
- 唯一约束去重（同一 surface + 来源不重复入库）
- 4 个索引加速按 language / source / cefr / production_ready 检索
- 字段：surface / phonetic / pos / meaning / example / cefr / source / `production_ready`

### 引擎包：`lexicon/`
| 模块 | 职责 |
|---|---|
| `normalize.py` | 大小写、空白、标点归一化 |
| `dedup.py` | 去重策略（保留信息量最大的一条） |
| `license_filter.py` | 许可证 / 商用授权过滤（读 `license_registry.json`） |
| `cefr.py` | CEFR 分级（A1–C2） |
| `validate.py` | 必填字段校验 |
| `sources.py` | 来源元信息定义 |
| `pipeline.py` | 编排上述步骤的导入流水线 |
| `db_io.py` | SQLite 批量落库（250 条/批） |
| `to_content.py` | 主词库 → `ContentItem` 的转换 |

### 轻量化约束
- SQLite **批量提交**（250 条/commit），无常驻内存全量缓存
- **无启动时导入**，只有显式执行脚本才跑
- 无重型依赖（不引入 pandas / numpy）
- 实测：English 5000 + Cantonese 2000 合计 7000 条，**峰值内存 11.5MB，DB 4.58MB**

## Mock 标注
**本版本不涉及外部 AI 调用**，无 mock 组件。
唯一与「模拟数据」相关的是 `synthetic-dev` 来源，它按 §36 规则**永不进入生产**。
