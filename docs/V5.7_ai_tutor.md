# V5.7 AI Tutor（provider 适配器 + mock）

## 目标
提供六类 AI 学习辅助能力，同时做到「**没接模型就绝不假装接了**」。

## 交付内容

### 服务层：`ai_tutor.py`（顶层模块）
> ⚠️ **不要移进 `services/` 包** —— 根目录已有顶层 `services.py`，同名包会在
> `import` 时遮蔽它并导致**整站崩溃**。

### 三条 provider 分支

| provider | 环境变量 | 默认模型 | HTTP 实现 |
|---|---|---|---|
| `mock`（**默认**） | — | `rule-based-local` | 无网络请求 |
| `openai` | `AI_API_KEY` | `gpt-4o-mini` | `POST /v1/chat/completions` |
| `anthropic` | `AI_API_KEY` | `claude-3-5-haiku-latest` | `POST /v1/messages` |

其它环境变量：`AI_PROVIDER` / `AI_MODEL` / `AI_BASE_URL` / `AI_TIMEOUT` / `AI_MAX_INPUT_CHARS`

> 所有 HTTP 走标准库 `urllib`，**不引入各家 SDK** —— 保持 Docker 镜像轻量，
> 符合 2vCPU-2GB 部署约束。

### 六类能力
`explain`（讲解）/ `example`（例句）/ `conversation`（对话）/
`correct`（批改）/ `translate`（翻译）/ `practice`（练习）

### API（`routes/ai_tutor.py`，前缀 `/api/ai-tutor`）
| 端点 | 方法 | 说明 |
|---|---|---|
| `/status` | GET | 当前 provider / model / 是否 mock / 可用能力 |
| `/<action>` | POST | body `{"text": "...", "lang": "zh"|"en"}` |

未登录返回 **401 JSON**；参数缺失 / 未知 action 返回 **422**；套餐不足返回 **403**。

## 🧪 Mock 标注（核心约定）

| 情形 | 行为 |
|---|---|
| 未配 `AI_API_KEY` | `status()["mock"] = true`，UI 显示「**本地规则模式**」 |
| 返回值 | 必定带 `"mock": true`，前端据此显示 Mock 徽章 |
| 真实 provider 出错 | **显式失败**返回 `ok=false`，**绝不**悄悄退化成 mock 冒充 AI 回答 |
| 设了 `AI_MODEL` 但没配 key | 仍显示 `rule-based-local`，**不显示** `gpt-4o-mini` |

### mock 不是瞎编
mock 结果来自**站内真实内容数据**（`ContentItem` 的释义与例句），是确定性规则，
而非随机生成的「听起来像 AI 的话」。

---

## 安全

- API Key 只从环境变量读，**不出现在任何返回值 / 日志 / 代码中**
- 入参：长度截断 + 控制字符清理 + **提示注入剥离**
  （`ignore previous instructions`、`you are now`、`system prompt` 等）
- `system prompt` **由服务端固定**，用户文本只进 `user` 角色
- 请求带超时；异常信息不回显 `Authorization`（只记录异常类型）
- 响应解析失败抛**受控 `RuntimeError`**，不让 `KeyError` 泄到上层

## 实现缺陷（测试暴露，已修）

| 问题 | 说明 |
|---|---|
| 字段名错误 | `ContentItem` 的字段是 **`meaning_cn`** 而非 `meaning_zh`，原引用会抛 `AttributeError` |
| mock 查词拿错文本 | 统一入口原本只拿到拼好的 prompt（`"Explain: good morning"`），**永远匹配不到站内词条**；改为 `_tutor()` 同时接收 `raw_text` 专供查词 |
| 空输入漏校验 | 因 prompt 模板非空而绕过；改为**在拼 prompt 之前**拦截 |
| 模型名误导 | 设了 `AI_MODEL` 没配 key 时显示真实模型名；改为未接通一律显示 `rule-based-local` |
| 页面自相矛盾 | 「规划中的 AI 能力」仍标「敬请期待」，与已可用的交互面板冲突；已替换为实际可用能力 |
