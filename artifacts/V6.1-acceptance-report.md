## 二、修改文件与功能清单

### 1. 退出登录功能（POST + CSRF）
- `auth.py`：`/logout` 由 `methods=["GET","POST"]` 改为 **`methods=["POST"]`**（GET 注销是已知 CSRF/强制登出攻击面，已加固）。
- `app/templates/base.html`：右上角退出按钮由 `<a href>` 改为 **POST 表单 + `csrf_token()` + 提交按钮**，保留门形图标（`logout`）与「退出登录」文字。
- `v4.css`：新增 `.logout-form` / `.logout-form .icon-btn` 样式重置，移动端（≤768px）仅显示图标避免溢出。
- `tests/test_flow.py`、`tests/test_ui_smoke.py`：原 2 处 `GET /logout` 用例同步改为 `POST /logout`（CSRF 在测试中关闭，仅验证行为）。

### 2. 右上角导航图标优化（语义 + 权限）
- `base.html`：收藏=`bookmark`、错题本=`list-checks`、管理后台=`dashboard`、退出=`logout`（门形）；三项均保留文字标签；管理后台链接仍由 `{% if current_user.is_admin %}` 包裹，**普通用户不可见**。

## 三、全量代码审计（范围 / 发现 / 修复）

**审计范围**：Python 路由（auth/routes）、模板、CSS、内联 JS、Dockerfile、docker-compose、依赖；认证/权限边界、CSRF、会话安全、输入校验、敏感信息；DB 迁移/兼容性、异常处理/日志；前后端交互；新增改动回归。

**发现与结论（真实，未伪造）**：

| # | 领域 | 发现 | 处置 |
|---|------|------|------|
| A | 会话/注销 | `/logout` 原接受 GET，存在强制登出 CSRF 面 | **已修复**：仅 POST + 全局 CSRFProtect（生产 `WTF_CSRF_ENABLED=True`） |
| B | CSRF | 生产配置已启用 CSRFProtect；测试配置关闭（预期） | 保留；`test_flow [10]` 验证「无 token 被拒 / 带 token 通过」 |
| C | 会话 Cookie | `SESSION_COOKIE_HTTPONLY=True`、`SAMESITE=Lax`；生产 `SECURE=True`（env 控制） | 符合最佳实践，无改动 |

| E | 权限 | 管理后台链接/路由均受 `is_admin` 控制 | 无改动；`test_flow [11]` 验证普通用户被拒 |
| F | 图标完整性 | 字典原缺 `chat/alert/help/close` 3 处被引用（会渲染空白） | **已修复**：补齐 4 键（含 `close`） |
